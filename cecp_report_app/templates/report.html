Methodology

Data source: {{ data.data_source }}. Figures cover Trend Vision One Cloud Email and Collaboration Protection detections for the stated period, across mailboxes (Exchange Online, Gmail) and collaboration apps (OneDrive, SharePoint Online, Microsoft Teams, Box, Dropbox, Google Drive). Only remediated detections are valued, because a threat that was only logged was not prevented. Potential loss avoided = (remediated detections of a threat type) × (IC3 loss-per-victim for its category) × (days in the period ÷ 91.25), summed by threat type. This is the same Potential Loss method as Trend Micro's TMES sheet and the CEGP report, so the two products' figures can be compared. Source for loss-per-victim figures: {{ ic3_source }}. This is a directional figure for illustrating security value, not an audited financial-loss calculation. For a customer-specific, FAIR-model-based risk figure, use Vision One's Cyber Risk Quantification (CRQ) capability instead.{% if data.simulation_excluded %} {{ "{:,}".format(data.simulation_excluded) }} simulation-mode detections were excluded.{% endif %}
